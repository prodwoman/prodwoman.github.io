## Design rule

Every screen has one primary action, so a user always knows what to do next.

## How it's built

Each product is a single self-contained HTML file with no build step. The AI features (plain-language understanding, summaries, drafts) run on Claude when opened inside claude.ai. On this site they fall back to built-in rules, so every flow still works.
